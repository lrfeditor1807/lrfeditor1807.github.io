WhatsApp Sticker Maker

Create a WhatsApp sticker pack named "Sample Sticker Pack" (client-side — no server required)

Upload images (PNG/JPG/WebP). They will be resized to 512×512 webp with transparency. A 96×96 tray image will be generated from the first sticker.

Click or drag images here (or use the Upload button)

Minimum 3 stickers for WhatsApp packs. Filenames inside the ZIP will be sticker1.webp, sticker2.webp, ...

Preview / Per-sticker options

You can remove images or add emojis for each sticker (emojis are optional and included in metadata).

Note: This tool creates a ZIP containing .webp stickers, a tray.png and metadata.json suitable for use by sticker-pack tooling and app templates (Android & iOS developer workflows). To add to WhatsApp you can:
  • Use a sticker-import app on Android or
  • Use the official WhatsApp sticker app template (developers) to build and install a pack
