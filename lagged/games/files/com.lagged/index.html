Use Start to run a staggered activation over every cell. Cancel will stop the ongoing run. Change rows/cols or order then rebuild the grid by pressing Start.

Order behaviors:
  • row: left→right, top→bottom
  • col: top→bottom, left→right
  • random: shuffled
  • spiral: inward spiral from top-left
